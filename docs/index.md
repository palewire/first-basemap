# First Basemap

Create a shockingly fast and virtually free interactive map of the world using OpenStreetMap and PMTiles

## What you will learn

* How to link a free [GitHub Actions](https://docs.github.com/en/actions) task runner to large-scale, long-running servers using [Amazon Web Services](https://aws.amazon.com/).
* How to configure [Planetiler](https://github.com/onthegomap/planetiler) to download [OpenStreetMap](https://www.openstreetmap.org/) data and convert it to the [PMTiles](https://github.com/protomaps/PMTiles) file.
* How to style and display the map using [MapLibre GL JS](https://maplibre.org/projects/maplibre-gl-js/).

## Who can take it

This course is free. Previous experience working with Amazon Web Services and GitHub Actions will be useful, but anyone with a good attitude is qualified.

If you have never made a GitHub Actions workflow before, you should review the first three chapters of [“Go big with GitHub Actions,”](https://palewi.re/docs/go-big-with-github-actions/) a previous course by [Ben Welsh](https://palewi.re/who-is-ben-welsh/), [Iris Lee](https://www.irisslee.com/) and [Dana Chiueh](https://dana.computer/).

They are [“Introducing Actions,”](https://palewi.re/docs/go-big-with-github-actions/what-are-actions.html) [“Introducing YAML”](https://palewi.re/docs/go-big-with-github-actions/what-is-yaml.html) and [“Creating your first Action.“](https://palewi.re/docs/go-big-with-github-actions/getting-started.html) They will teach you the basics you need to work through this class.
